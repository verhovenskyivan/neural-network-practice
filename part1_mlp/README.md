# Часть 1 — полносвязный MLP

Запуск из корня проекта: `python -m part1_mlp.app.main`.
Вход: `data/input/classification.csv` (первый ряд — названия признаков, последний столбец — целевая метка 0/1).
Сначала создайте сеть 2→8→1, затем загрузите CSV, обучите и выполните прогноз.
Поддерживаются `relu`/`sigmoid`, мини-батчи, `BCE`, сериализация JSON вместе с параметрами стандартизации.
Для восстановления меню 5→2. Целевая задача — бинарная классификация, не регрессия и не многоклассовая классификация.
