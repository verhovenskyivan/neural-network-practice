# Практическая работа «Основы нейронных сетей»

Рабочий учебный проект в трёх частях. Python 3.9+.

## Установка

Из каталога проекта: `python -m pip install -r requirements.txt`.

## Запуск

1. ООП-нейросеть: `python -m part1_mlp.app.main`.
2. Проверка окружения: `python -m part2_prepare.app.cli doctor`.
3. Подготовка PNG: `python -m part2_prepare.app.cli prepare --path data/input/images --ext .png --output data/output/prepared.npy --size 32`.
4. Подготовка CSV: `python -m part2_prepare.app.cli prepare --path data/input --ext .csv --output data/output/prepared_csv.npy` (исходный CSV должен содержать заголовок и только числовые значения).
5. CPU-аугментация: `python -m part3_parallel.app.performance --path data/input/images --threads 3 --processes 2 --copies 2`.
6. Тесты: `python -m unittest discover -s tests -v`.

В репозитории сохранены тестовые данные и образцы результатов выполнения, включая логи, график ошибки и `performance_report.json`.

Файл `.env.example` перечисляет переменные окружения. Программа использует `os.getenv`; чтение `.env` не требуется и намеренно не включено в зависимости.

## Сведения об архитектуре

* Part 1: бинарный MLP (скрытые sigmoid/ReLU, на выходе сигмоида, BCE и мини-батчевый SGD); статистики нормализации вычисляются по обучающей части и сохраняются с весами.
* Part 2: CLI с argparse, pathlib, Pillow и NumPy; CPU-версия не нуждается в CUDA. Изображения приводятся к одинаковому размеру. При обработке CSV MinMax применяется ко всем числовым столбцам: для моделирования обучающего процесса целевые метки лучше обрабатывать отдельно.
* Part 3: очередь путей для производителя, очередь массивов потребителей, Lock, пул процессов и сравнение результатов по элементам. Время включает чтение, передачу данных и создание пула.

## Практические ограничения

Демонстрационный набор изображений небольшой; увеличение числа процессов не гарантирует ускорение. На больших наборах накопление всех массивов в оперативной памяти может вызвать Out Of Memory. Для производственного применения требуются потоковая запись батчей, ограниченные очереди и блочное чтение.
